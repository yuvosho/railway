# Checklist SEO Semanal - Valsho.com.ar

## Meta Tags
- [ ] Title tag tiene 50-60 caracteres con keyword principal
- [ ] Meta description tiene 150-160 caracteres con CTA
- [ ] Canonical URL configurada correctamente
- [ ] Open Graph tags completos (og:title, og:description, og:image)
- [ ] Twitter Card configurada
- [ ] Meta viewport presente
- [ ] Atributo lang="es" en html

## Estructura de Headings
- [ ] Solo 1 H1 por pagina
- [ ] H1 contiene keyword principal
- [ ] Jerarquia correcta (H1 > H2 > H3, sin saltos)
- [ ] H2 en secciones principales de contenido

## URLs
- [ ] URLs amigables (slug format, sin caracteres especiales)
- [ ] Sin URLs duplicadas
- [ ] Redireccion 301 de www a no-www (o viceversa)
- [ ] HTTPS en todas las paginas

## Contenido
- [ ] Keywords del sector en titulo y descripcion de productos
- [ ] Descripciones unicas por producto (no duplicadas)
- [ ] Contenido minimo 300 palabras en paginas principales
- [ ] Internal linking entre categorias y productos

## Tecnico
- [ ] robots.txt actualizado y accesible
- [ ] sitemap.xml actualizado con todas las URLs
- [ ] Sin errores 404 en links internos
- [ ] Velocidad de carga < 3 segundos en mobile
- [ ] Sin contenido duplicado

## Schema Markup
- [ ] Schema Product en paginas de productos (nombre, precio, imagen, disponibilidad)
- [ ] Schema Organization con datos del negocio
- [ ] Schema BreadcrumbList para navegacion
- [ ] Validar en Google Rich Results Test
